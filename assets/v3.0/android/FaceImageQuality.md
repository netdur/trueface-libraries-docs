# FaceImageQuality

## `public enum FaceImageQuality`

Describes the quality of a face image to be used for face recognition.

### Enum Constants

#### `GOOD`

The quality of the image is good for face recognition.

#### `UNDER_EXPOSED`

The image is underexposed.

#### `OVER_EXPOSED`

The image is overexposed.

#### `BLURRY`

The image is blurry.
