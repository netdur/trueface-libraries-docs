# RotateFlags

## `public enum RotateFlags`

Flags used for rotating images.

### Enum Constants

#### `ROTATE_0`

Do not rotate.

#### `ROTATE_90_CLOCKWISE`

Rotate 90 degrees clockwise.

#### `ROTATE_180`

Rotate 180 degrees clockwise.

#### `ROTATE_90_COUNTERCLOCKWISE`

Rotate 270 degrees clockwise (or 90 degrees counterclockwise).
