# BoundingBox

Bounding box for detected objects.

## Fields

- `ObjectLabel label` - The object class as a label. See [ObjectLabel](/v3.0/android/ObjectLabel).
- `float probability` - The detection's confidence probability.
- `Point topLeft` - The top left corner [Point](/v3.0/android/Point) of the bounding box.
- `float width` - The width of the bounding box.
- `float height` - The height of the bounding box.
