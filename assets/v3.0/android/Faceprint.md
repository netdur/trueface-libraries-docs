# Faceprint

Face feature vector and associated metadata.

## Fields

- `List<Float> featureVector` - Vector of floats describing the face.
- `String sdkVersion` - SDK version used to generate the feature vector.
- `String modelName` - Name of the model used to generate the feature vector.
- `ModelOptions modelOptions` - Options used when generating the feature vector. See [ModelOptions](/v3.0/android/ModelOptions).
